# Dự án: Cross-border Payments trên Blockchain (môn Blockchain – thạc sĩ Fintech UEB)

## Mục tiêu
Demo chuyển tiền xuyên biên giới bằng stablecoin giả lập trên testnet Ethereum Sepolia:
người lao động ở nước ngoài gửi vJPY/vKRW/vTWD/vUSD, người nhận ở Việt Nam nhận vVND
trong MỘT giao dịch. Chỉ dùng testnet, không tiền thật.

## Kiến trúc (không database, không server backend)
- `contracts/StableToken.sol`: ERC-20 (OpenZeppelin), 18 decimals, `faucet()` 1 lần/24h, chỉ owner được mint.
- `contracts/FXHub.sol`: quỹ hoán đổi mô hình TRỤC USD — mỗi đồng tiền một quỹ ghép với vUSD.
  - Công thức AMM x*y=k, phí 0,3% mỗi chặng.
  - Quản trị: `listToken`, `addLiquidity`, `removeLiquidity`, `pause`/`unpause` (Ownable, Pausable).
  - `quote(fromToken, toToken, amountIn)` (view).
  - `sendCrossBorder(fromToken, toToken, amountIn, minOut, recipient)`: 3 trường hợp — từ USD, về USD, hoặc 2 chặng qua USD.
  - Event `Remittance(sender, recipient, fromToken, toToken, amountIn, amountOut)`.
  - Bảo mật: ReentrancyGuard, SafeERC20, checks-effects-interactions, kiểm tra `minOut`, recipient != address(0).
- Coin: vUSD (trục), vVND, vJPY, vKRW, vTWD (vEUR tuỳ chọn). Làm chạy với vUSD + vVND trước rồi mới mở rộng.
- Frontend: thư mục `frontend/`, Vite + JavaScript thuần + ethers.js v6, kết nối MetaMask.

## Công cụ
- Hardhat 3 (ESM, `hardhat.config.ts`), mẫu dự án **Mocha + Ethers.js**; deploy bằng Hardhat Ignition.
- Node.js >= 22.13.
- Bí mật (RPC URL, private key ví dev, Etherscan API key) lưu bằng `npx hardhat keystore set ...`,
  đọc bằng `configVariable(...)`. KHÔNG BAO GIỜ ghi private key vào code, file commit, hay dán vào chat.

## Cách làm việc
- Làm TỪNG BƯỚC theo kế hoạch bên dưới, dừng lại sau mỗi bước để tôi kiểm tra rồi mới làm tiếp.
- Mỗi bước phải có đầu ra chạy được: `npx hardhat build` và `npx hardhat test` xanh trước khi sang bước sau.
- Comment code bằng tiếng Việt, ngắn gọn, để cả nhóm (không chuyên dev) đọc hiểu và trả lời vấn đáp.
- Trả lời tôi bằng tiếng Việt, đơn giản; gặp khái niệm mới (approve, reentrancy, BigInt...) thì giải thích 1–2 câu.
- Không cài thư viện ngoài danh sách trên nếu chưa hỏi tôi.
- Trước khi chạy lệnh có thể xoá/ghi đè file, hỏi tôi trước.
